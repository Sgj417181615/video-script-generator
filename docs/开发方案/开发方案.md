# MelonAI 视频创作系统 · 开发方案

## 一、项目定位

### 1.1 是什么
MelonAI 是一个面向 **AI & Agent 主题短视频创作** 的文案生成与知识管理体系。
帮助创作者从灵感→文案→分镜→复盘全流程管理，所有产出沉淀到 Obsidian 知识库。

### 1.2 不是什么
- ❌ 不是大西瓜软考 APP 的营销工具（那个归 `📱营销素材/`）
- ❌ 不是通用文案生成器（聚焦 AI 主题）
- ❌ 不是课程/教程平台

### 1.3 品牌
- **系列名**：MelonAI 说人话
- **Slogan**：让 AI 不再高冷
- **一句话价值主张**：让打工人用最少的时间，跟上 AI 时代，守住并放大自己的价值
- **目标受众**：被工作/生活琐事填满、怕被时代丢下的打工人（非技术背景）
- **内容原则**：不追求最专业，追求最易懂；利他具体化——每条给一个"带得走的行动"
- **账号宪法**：定位与人设的完整定义（人设/受众/六维度/红线/出片自检清单）见 `D:\DatasPath\Knowledge\wiki\MelonAI\账号宪法.md`，为**唯一权威**，所有文案必须遵循

## 二、系统架构

### 2.1 整体数据流

```
┌─────────────────┐     ┌──────────────────┐     ┌────────────────┐
│  Claude Code     │────▶│ generate_script  │────▶│  Obsidian       │
│  (/melona skill) │     │ .py (Deepseek)   │     │  知识库         │
│                  │     │ 快速模式          │     │  (存储沉淀)     │
│  引导讨论        │────▶│ ──────────────── │────▶│                │
│  梳理要点        │     │  Claude 直接创作  │     │  MelonAI/      │
│  迭代优化        │     │ 深度打磨模式      │     │   ├─ 创意池    │
│  创建记录        │     │                  │     │   ├─ 话题地图  │
│  更新索引        │     │                  │     │   ├─ 已产出/   │
└─────────────────┘     └──────────────────┘     └────────────────┘
        │                                               │
        │         ┌──────────────────┐                   │
        └────────▶│  raw/ 收件箱      │◀──────────────────┘
                   │  外部素材 → 提炼  │
                   └──────────────────┘
```

### 2.2 双模式文案生成

| 维度 | 快速模式（脚本） | 深度打磨模式（Claude） |
|------|----------------|---------------------|
| 触发条件 | 用户有明确主题、赶时间 | 用户想边聊边写、迭代 |
| 引擎 | Deepseek API（`generate_script.py`） | Claude |
| 输出 | 自动生成 Markdown 到 MelonAI/已产出/ | 对话中逐步定稿 |
| 优势 | 快速出一版，复用 API 配置 | 灵活迭代，可以边聊边调 |
| 风险 | API 可能异常（已遇到 JSON 解析错误） | 依赖 Claude 会话 |
| 建议 | 优先尝试，失败切换 | 兜底方案，适合需要精修的内容 |

### 2.4 信息抓取 → Excel 流水线

把"从互联网抓信息 → 核实真实性 → 提炼结构化要点 → 导出 Excel"做成可复用流水线（skill + 脚本双落地）。

| 环节 | 实现 | 说明 |
|------|------|------|
| 触发 | Skill「抓取信息并提炼要点保存excel」 | 用户说"抓取/搜集最新XX信息""整理成Excel"时调用 |
| 抓取 | 并行 WebSearch（中英双源） | 官方域名优先，关键数字 ≥2 源交叉一致才写实 |
| 核实 | ✓/△ 双列标注 | 官方已确认（✓）vs 媒体报道·待核实（△），不混写 |
| 导出 | `generate_top3_excel.py` → `桌面/结果/MelonAI_Top3选题信息表.xlsx` | Top3 选题全字段（标题/一句话/要点/脚本/分镜/钩子/来源URL/核实状态/账号联动/制作备注） |

**真实性铁律**：能确认说"已确认"，不能确认说"待核实"；每条可溯源，绝不把媒体推测当官方事实；访问不了的域名如实说明。

### 2.5 PPT 生成（实验，三条路线对比）

打工人视角 AI 要闻出 PPT 的方案探索，内容源：`PPT生成/内容/今日三大AI要闻_打工人视角.md`。

| 路线 | 目录 / 脚本 | 技术栈 | 产出 |

| 清理 raw/ | `/melona → [5]` | 归档/清理已处理素材 |

### 3.2 创意记录模板（9 项）

每期视频必须包含以下完整信息链，缺一不可：

```
① 基本信息      → 状态/系列/平台/时长/语气/框架
② 原始想法      → 逐字保留用户灵感原话
③ AI 提示词     → 逐字保留全部输入，不做提炼
④ 用户修改意见  → 逐字记录具体修改要求
⑤ 钩子迭代过程  → 每轮钩子原文 + 用户反馈
⑥ 优化过程      → v1/v2/v3 各版本变更记录
⑦ 最终文案      → 定稿口播台词全文
⑧ 分镜脚本      → 时间段 × 画面 × 台词表格
⑨ 复盘总结      → 做对的/踩坑的/下次改进
```

**每条记录还必须有：**
- ✅ 相关链接（`[[话题地图]]`、关联视频、关联知识）
- ✅ 标签（`#MelonAI` + 系列标签 + 话题标签）

### 3.3 抓取信息并提炼要点保存excel

| 功能 | 命令/触发 | 说明 |
|------|-----------|------|
| 抓取 → Excel | 用户说"抓取/搜集最新XX信息""提炼要点""整理成Excel" | 并行搜索 → 官方优先 → 交叉核实 → ✓/△ 标注 → 导出 `桌面/结果/MelonAI_Top3选题信息表.xlsx` |
