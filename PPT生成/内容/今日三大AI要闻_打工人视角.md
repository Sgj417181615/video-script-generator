## 话题一 · DeepSeek-V4-Flash 正式版发布

### 一句话选题

美国顶级 AI 刚降价 80%，因为国产免费版追上来了。

### 核心事实

- 2026-07-31 正式版 API 上线公测，现有集成不改代码即可自动升级
- 轻量化 MoE 架构：总参数 284B / 激活 13B，支持 1M 超长上下文
- 官方 9 项 Agent 基准中多项超过三个月前的 V4-Pro 预览版
- 原生兼容 OpenAI Responses API 格式，针对性适配 Codex
- 百万 Token 场景单 Token 算力仅为前代的 27%，价格极低
- 支持思考 / 非思考模式切换

### 关键数据

| 指标 | 数值 |
|---|---|
| 总参数 | 284B |
| 激活参数 | 13B |
| 上下文 | 1M tokens |
| 单Token算力 | 前代的 27% |
| 价格 | 缓存命中输入约 $0.0028/百万token |

### 打工人视角

顶级干活能力 + 极低成本 → 普通打工人也能用上顶尖模型，选工具不用迷信国外付费产品；拆掉"必须花钱买课/买会员才能用好 AI"的焦虑。

## 话题二 · OpenAI Astra：AI 花 2000 美元连破 10 道数学世纪难题

### 一句话选题

上次 AI 自己跑出去闯祸，这次它自己干了四天正事：10 道人类卡了多年的数学题。

### 核心事实

- OpenAI 官方博客首次公开下一代模型 Astra（"our next major model"）的内部版本
- 在 10 个长期未决的数学 / 理论计算机科学难题上做出新结果
- 领域涵盖：高维几何、编码理论、群论、量子复杂性、格密码学等
- 每个论证用 Lean 4 形式化验证，证书公开在 GitHub
- 共发布 249 页手稿合集 + AI 推理过程旁白
- 官方称全部 token 成本约 2000 美元

### 关键数据

| 指标 | 数值 |
|---|---|
| 解出的难题 | 10 道 |
| 手稿 | 249 页 |
| Token 成本 | 约 $2000 |
| 验证方式 | Lean 4 形式化 |
| 模型 | Astra（next major model 内部版） |

### 打工人视角

数学难题本身离打工人远，但内核是：AI 从"答一句"升级到"独立干一件长活"——以后你可以把整件工作交给 AI，而不是一句一句喂。接续上一期"AI 自己干活没人盯会闯祸"，这次是"AI 干长活立了功"。
